# Known limitations

- Actual publication is disabled by default. Production publication dependencies and delivery have not been fully connected or verified. Plan publication as a separate, manually verified operation until the required dependencies and delivery path are connected.
- The B18 check before sending to a sandbox is disabled by default because no publication-classification classifier is available. While it is disabled, all transmissions to the sandbox are rejected. Sandbox requests cannot proceed through that path. Supply and validate the missing classifier before enabling it.
- Explicitly clearing a revocation requires restarting the adapter. An adapter can continue enforcing a revoked state after it is cleared; restart the affected adapter to reload it.
- The T-68 security watch is registered in a stopped state. Live provisioning, SSH, and notification delivery remain unverified. Do not rely on this watch for live detection or notifications; provision and validate those paths before use.
- The change-ops GitHub adapter alone rejects cancellation requests; trusted pull-request identity and the shared ledger are required. Cancellation through that adapter alone cannot establish a safe outcome. Use the trusted identity and ledger path and inspect the PR state.
- `work.resume` is not implemented. A cancellation request does not prove that an already running job has stopped. Check the actual job state after cancellation; arrange a new request only after the outcome is known.
- Production second-factor notifications are not connected; end-to-end identity and delivery are unverified. Do not rely on production second-factor notification delivery until the complete identity and delivery path is verified.
- Remote SSH execution supports the `audit-readonly` entry point, not general manifest-defined entry points. Existing Instabox sandboxes can be used, but their creation and deletion are unsupported. Choose a supported entry point and provision an existing sandbox independently; broader SSH execution and sandbox lifecycle operations remain future work.
- Sandbox and environment jobs do not yet share atomic capacity arbitration. An uncertain remote outcome retains its reservation until reconciled. Independent admission can exceed a shared capacity expectation. Inspect and reconcile uncertain outcomes before freeing reservations.
- Control-to-cap wiring and the aggregate free-tier cap are incomplete. Conversation indexing requires explicitly configured inputs and a registered embedding endpoint. Do not assume that all controls enforce every cap. Configure the indexing inputs and embedding endpoint explicitly, and monitor the affected feature.
- Image scanning does not include image recognition or inspection of compressed image content. Core and CI Dockerfiles use mutable image tags by default unless build arguments override them. Images can contain material the scanner cannot inspect. Use additional review and explicitly pinned build inputs where required.
- External operations have been tested with simulated dependencies; live deployment, SSH, notification delivery, and actual publication have not been verified. Treat simulated results as integration evidence only. Validate each external dependency in its target environment before relying on it.
