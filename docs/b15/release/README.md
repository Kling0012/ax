# 公開待ちと製品公開

公開待ちは `repo` と `pr` の組で重複を防ぐ。対象パスに変更がなければ省略し、変更パスを取得できなければ保留する。自動公開が無効なときも、未公開の待ちを記録する。

バッチは最後のマージからの静穏時間か、最初の待ちからの上限時間で確定する。確定したバッチの対象 SHA と PR は変えない。同じリポジトリと公開モードの処理は直列化する。

公開は既定で dry-run である。dry-run はノートと実行予定を作るが、外部の状態を変えない。実公開では許可、試験証拠、公開ゲート、製品固有の確認を満たす必要がある。外部操作の結果が不明なときは、照合できるまで再送しない。
