3. [CLI リファレンス](cli-reference.md) で状態の確認や依頼の送り方を確認します。
4. [運用ガイド](operations.md) と [トラブルシューティング](troubleshooting.md) で日常の確認、更新、復旧方法を確認します。

## 利用上の注意

マニュアルは作業中の文書です。接続の一部は暫定で、`DEFERRED` と書かれた操作は利用できません。設定やロックファイルが存在しても、対象環境でのビルドや実行が成功するとは限りません。実際に動かす前に環境と依存サービスを確認してください。
