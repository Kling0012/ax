# B10a 予備役・緊急ボタン・通知

B10a は管理役の停止への対処、HQ の緊急ボタン、通知の配送を扱う。

| 手順書 | 担当する機能 |
|---|---|
| [予備役](standby/README.md) | オブザーバーから管理役の周回を呼び、根本原因の ToDo を残す |
| [緊急ボタン](emergency/README.md) | 状態の記録、命令の解除、再開とホストへの再起動要求 |
| [通知配送](notify/README.md) | ntfy の配送、再通知、朝の要約、HQ の操作経路 |

配備定義は `compose.d/b10a.yaml` に置く。予備役は `observer`、通知配送は `hq` への追加定義になる。緊急処理は `emergency` サービスで動く。各部品の基本定義と合わせて読み込む。

B10 完成時の予備役のモデルの確認は DESIGN.md の D-17 に従う。モデルの選択は予備役の担当が扱う。
